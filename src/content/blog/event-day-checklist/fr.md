La plupart des problèmes d’événement viennent d’une tâche dont personne n’était responsable. Cette check-list répartit le travail dans le temps pour que chaque point ait une échéance et, idéalement, un nom à côté. Adaptez les délais : un atelier de 30 personnes demande moins d’anticipation qu’une conférence de 500.

## Quatre semaines avant

- [ ] Confirmer le lieu par écrit : capacité, horaires, accessibilité, Wi-Fi, prises électriques.
- [ ] Réserver les prestataires clés : traiteur, photographe, technique audiovisuelle, ménage s’il n’est pas inclus.
- [ ] Publier la page d’inscription avec le programme, l’adresse et la politique photo.
- [ ] Rédiger le déroulé minuté.
- [ ] Désigner un responsable par zone pour le jour J : accueil, scène, buffet, intervenants.

## Deux semaines avant

- [ ] Envoyer le [brief photographe](/fr/blog/event-photographer-brief) et le déroulé aux prestataires.
- [ ] Récupérer les présentations des intervenants et vérifier qu’elles s’ouvrent sur le matériel du lieu.
- [ ] Commander badges, signalétique et supports imprimés.
- [ ] Préparer [l’accueil des invités](/fr/blog/guest-welcome-desk) : disposition, équipe, format de la liste.
- [ ] Prévoir un plan B pour les moments en extérieur.

## La semaine précédente

- [ ] Envoyer aux invités un rappel pratique : heure, adresse, accès, ce qu’il faut apporter.
- [ ] Confirmer le nombre définitif au traiteur.
- [ ] Partager une fiche contacts avec le téléphone de chaque prestataire et membre de l’équipe.
- [ ] Imprimer le déroulé, la liste des invités et la fiche contacts.
- [ ] Préparer une caisse : scotch, ciseaux, feutres, rallonges, chargeurs, trousse de secours, badges vierges.

## Le jour J

- [ ] Arriver avant les prestataires pour ouvrir le lieu et vérifier l’installation.
- [ ] Tester micros, vidéoprojecteur et présentations dans la vraie salle.
- [ ] Briefer l’équipe en dix minutes : rôles, horaires, qui tranche si le planning glisse.
- [ ] Faire le tour du lieu avec le photographe.
- [ ] Garder une personne sans tâche fixe pour gérer les imprévus.

## Le lendemain

- [ ] Remercier intervenants, prestataires et bénévoles.
- [ ] Envoyer aux invités un court message avec la suite et, quand elles sont prêtes, les photos.
- [ ] Noter ce qui n’a pas fonctionné tant que c’est frais, avec la correction pour la prochaine fois.
- [ ] Régler les prestataires et clôturer le budget.

Imprimez cette liste, attribuez chaque ligne à quelqu’un et faites le point à chaque réunion d’équipe. Une case cochée n’est utile que si tout le monde s’accorde sur ce que « fait » veut dire.
